# The phone's Python stack: what the shell's Chaquopy pip block installs into
# the APK, and what tools\phone_env.bat installs on the laptop so a payload
# can be boot-tested before an APK exists.
#
# Why these and not the desktop's pins: pydantic-core (pydantic v2's Rust
# core) has no Android wheel anywhere - not in Chaquopy's index, not on PyPI
# (checked 2026-09-09) - so the phone runs pydantic v1, and app/config.py in
# the desktop repo carries the v1/v2 compat base every model inherits.
# fastapi 0.125.0 is the newest release whose metadata still accepts
# pydantic v1. cryptography 42.0.8 is the newest Chaquopy builds for Android
# (cp310-cp313, arm64-v8a); pyOpenSSL 24.3 is the newest that accepts it.
# Everything else is pure Python and ships as a py3-none-any wheel.
#
# Resolved 2026-09-09 on Python 3.11.9 from:
#   pip install "pydantic<2" fastapi uvicorn websockets asyncua==2.0.1 cryptography==42.0.8 "pyOpenSSL<25"
